## 一、验收总则（所有条目上线前必须全部满足）

1. **编译通过**：`./gradlew assembleDebug` 零 error。
2. **全原生零 WebView 零网络**：不允许 WebView 容器；运行期不发任何网络请求（含发音/音频）。⚠️ 冲突提示：V7.0 的 `WordSpeaker` 美音依赖有道 dictvoice 联网（见 ACC-38），迁移时需决策：移除发音 / 改离线 TTS，二选一，不得保留联网请求。
3. **返回键 = 上一级**：全局返回键行为必须等于「回到上一级视图」，战斗中按返回弹二次确认（详见 ACC-25）。
4. **DB 升级兼容现有数据**：进度存储升级时不得清空/破坏用户已有学习进度（localStorage key → Android 存储映射见 ACC-23）。
