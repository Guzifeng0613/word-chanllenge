## 2. 连击里程碑横幅（showComboBanner / comboBanner）

HTML 规格（JS 2599–2617、CSS 729–743）：
- 每 **5 连击**触发一次全屏横幅（z-index 112，约 1.1s 动画）。
- 主文案 `COMBO ×N`（54px/900，白金渐变文字 + 金色 drop-shadow）。
- 副标题与颜色分级：
  - **5 连击 = 手感火热（绿）**
  - **10 连击 = 连击高手（金）**
  - **15 连击 = 输出爆表（橙）**
  - **20 连击 = 势不可挡（紫）**
- 连击数字本身颜色同步分级（c5 绿 / c10 金 / c15 橙 / c20 紫，带辉光）。
- 触发时 **EPIC（comboMilestone）音效** + **多段震动**（≥15：[20,30,20,30]；否则 18）。

验收要点：分别在 5/10/15/20 连击截图，确认横幅文案、副标题、颜色分级；确认音效与震动（日志/代码佐证）。

## 3. 快答 PERFECT / GOOD（showJudgeGrade / judgePop）

HTML 规格（JS 2356–2361、2628–2635，CSS 744–751）：
- **拼写题**按剩余时间比例：剩余 ≥ **75%** → `PERFECT`；≥ **45%** → `GOOD`；否则无。
- **选择题**按耗时：≤ **3s**（C.speed.fastT）→ `PERFECT`；≤ **6s**（C.speed.normalT）→ `GOOD`。
- 弹字（约 0.8s，从上方放大上浮）：PERFECT 金色、GOOD 青色，各带辉光。

验收要点：拼写题快速作答截 PERFECT、中等速度截 GOOD；选择题 ≤3s 截 PERFECT、≤6s 截 GOOD；确认阈值与颜色。

## 4. 战斗入场横幅（battleIntro）

HTML 规格（JS 2642–2651，CSS 764–772）：
- 非快刷开局：约 **1.2s** 全屏层，居中显示
  - 层名（如「第 N 层 · 词境」，17px/700，青色，字距 4）
  - 怪物 emoji（46px）
  - 敌人名（38px/900，红色辉光）
  - 背景径向深蓝（`rgba(13,24,40,.5)`→`.88`）。
- **快刷模式不打断**：不显示入场横幅。

验收要点：远征/无尽开局截入场横幅（层名+emoji+敌人名）；确认快刷开局无此横幅。

## 5. 抽卡稀有度光柱 / 击杀闪光（RewardDrawView rarityRay / killFlash）

HTML 规格（JS 2636–2641、2594–2598，CSS 753–761、723–726）：
- 抽卡翻开时，稀有度 **r1 = 蓝色光柱**、**r2 = 紫色光柱**，从底部升起，约 **1.5s**，r1 宽 70、r2 宽 90；r0 无光柱。
- 击杀敌人：全屏白/金径向闪光（`radial-gradient at 50% 30%`，白 .55→金 .15），约 **0.5s**。

验收要点：抽卡 r1 截蓝光柱、r2 截紫光柱、r0 确认无；击杀瞬间截白金径向闪光。

## 6. 倒计时危机（timer.danger / Sfx TICK）

HTML 规格（JS 2227–2244，CSS 773–777）：
- 最后 **3 秒**：计时条与计时文本变红、0.5s 缩放脉冲（timerDanger）。
- 每秒滴答一次（Sfx `TICK`，880Hz 短音）。
- 计时文本：>3s 显示整数；≤3s 显示**一位小数**（HTML 现为始终一位小数，原生以「>3s 整数、≤3s 一位小数」为准，需对照确认）。

验收要点：战斗倒计时进入最后 3 秒截图，确认红色+脉冲；确认每秒滴答（日志/代码佐证）；确认计时文本格式。

## 7. 顶部 Toast 系统 / 词性标签（TopToast）

HTML 规格（CSS 782–803）：
- Toast 固定在**顶部**（safe-area + 10px），**不遮挡**内容，pointer-events 透传。
- 支持**排队 / 合并**（同内容合并），按顺序出现与消失。
- 类型配色：success 绿 / error 红 / info 琥珀（默认蓝）。
- 词性标签 `.posbadge-inline`：`white-space:nowrap`，**不换行**、不被挤压。

验收要点：触发成功/失败/信息提示各截顶部 Toast；连续触发确认排队/合并、不遮挡；长句词性标签确认 nowrap 不换行。
